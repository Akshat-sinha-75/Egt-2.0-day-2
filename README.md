# EGT 2.0 Treasure Hunt Platform

Platform for managing Round 1 and Round 2 of the Treasure Hunt event.

## Repository Structure

```text
├── frontend/    # Client-side user interface (Round 1 & Round 2, Admin portal)
├── backend/     # Serverless functions, database schemas (Supabase), validations & business logic
└── README.md
```

## Work Breakdown

- **Frontend Team:** Work exclusively within `/frontend`.
- **Backend Team:** Work exclusively within `/backend`.
