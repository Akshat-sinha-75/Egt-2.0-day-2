# Bharat Buildathon — Wizarding Edition Frontend

Modern React application built with Vite for the Bharat Buildathon Wizarding Edition.

## Features

- **The Great Duel:** Interactive Harry vs. Voldemort wand duel featuring canvas-driven spell beams, plasma orb clash, projectile tracking, impact bursts, 3D card tilt, image cutout filtering, and victory screens.
- **Wizarding Examination:** O.W.L. exam card with floating candles, local storage house points tracking, liquid button ripples, and golden spark physics.
- **The Grand Hall:** Constellation SVGs, spinning astral rings, and 6 interactive floating magical objects (Golden Snitch with flapping wings, bubbling potion, owl, broom, letter, lightning) that respond magnetically to cursor and touch movements.
- **Cinematic Footer:** Rising embers, social channels with spark effects, credits popup, and smooth back-to-top navigation.

## Development

```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
