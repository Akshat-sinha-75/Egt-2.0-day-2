# Frontend

This directory is reserved for the Frontend application (Round 1 & Round 2 Participant & Admin interfaces).

### Proposed Tech Stack:
- React + TypeScript (Vite)
- Tailwind CSS / Vanilla CSS
- Supabase Client SDK

### Main Responsibilities:
- **Round 1:**
  - Login Page (Team ID + Event Pass)
  - Question / Solving Dashboard (Q1–Q10 numerical questions + Q11 10-letter code)
  - Live Countdown & Hint Modals
  - Results Screens (Qualified #1-20, Completed Not Qualified #21+, Time Expired)
  - Admin Dashboard (Live monitoring, hints toggles, broadcasts, manual close)
- **Round 2:**
  - Checkpoint Scanner / Authentication View (Mobile-optimized)
  - Checkpoint Question & Submission View
  - Clue / Next Destination Reveal Screen
  - Final Destination / Completion Page
