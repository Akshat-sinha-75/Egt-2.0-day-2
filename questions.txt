ROUND 2 — THE TECHNICAL QUESTIONS
Difficulty Progression: Easy → Hard (6 variants of each of the 6 original challenge types)
1. 🎩 The Binary Sorting Hat
Difficulty: Easy
Concept: Binary Conversion + Sorting
The Sorting Hat has gone haywire and is assigning students using a magical binary system.
Each student is represented by an 8-bit binary number. The Hat receives:
00111001, 00001100, 10001100, 01111101, 01110010
Convert each binary number into decimal and sort them in ascending order.
Then calculate:
(decimal value of the 2nd number) + (decimal value of the 4th number)
What integer should you enter?
2. 🧹 The Quidditch Score Spell
Difficulty: Easy–Moderate
Concept: Loops + Conditional Statements
During a magical Quidditch practice, the following energy scores are recorded:
14, 5, 13, 29, 13, 21, 10
The magical scoreboard starts with a score of 0.
For each value:
If the value is divisible by 3, add twice the value to the score.
Otherwise, if the value is even, add the value to the score.
Otherwise, subtract the value from the score.
After processing all the values, multiply the final score by 2.
What integer should you enter?
3. 🧹 The Vanishing Spell
Difficulty: Moderate
Concept: Sliding Window / Two Pointers
A magical energy sequence is:
12, 6, 12, 12, 7, 9, 3, 20, 6, 18, 8, 6
Hermione must examine every window of 3 consecutive values. However, the Vanishing Spell has an additional rule:
Only windows whose first and last values are both odd are considered valid.
Among all valid windows, find the maximum window sum. Then calculate:
maximum valid window sum × total number of windows checked
What integer should you enter?
4. 🧹 Snape's Potion Sequence
Difficulty: Medium–Hard
Concept: Monotonic Stack / Next Greater Element
Snape has potion powers arranged in the following order:
31, 2, 18, 34, 13, 36, 8, 29, 22
For every potion, find the first potion to its right with greater power. Then:
1. Find all distinct Next Greater potion values.
2. Add those distinct values.
3. Count the number of potions with no Next Greater value.
Finally, calculate:
(sum of distinct Next Greater potion values) − (number of potions with no Next Greater value)
What integer should you enter?
5. 🗺️ The Marauder's Map — Hidden Route
Difficulty: Hard
Concept: Graph Filtering + Prime Numbers + Shortest Path
The Marauder's Map shows locations connected by magical corridors. Each corridor has a travel time.
A wizard can travel only through corridors whose travel time is a prime number.
The corridors are:
Hogwarts -> Hogsmeade = 29
Hogwarts -> Forbidden Forest = 29
Hogsmeade -> Diagon Alley = 3
Hogsmeade -> Azkaban = 6
Diagon Alley -> Azkaban = 2
Diagon Alley -> Ministry = 8
Azkaban -> Ministry = 11
Forbidden Forest -> Ministry = 14
Ministry -> Gringotts = 29
Starting from Hogwarts, reach Gringotts using only valid corridors.
Find the minimum total travel time, then multiply it by the number of corridors used.
What integer should you enter?
6. 🎒 The Room of Requirement — Knapsack Spell
Difficulty: Hard
Concept: 0/1 Knapsack / Optimization
Hermione finds six magical objects. Her enchanted bag can carry at most 13 units of weight. She wants to maximize the total magical power she can carry.
Object — Magical Power — Weight
Wand — 9 — 2
Cloak — 14 — 6
Time Turner — 11 — 5
Marauder's Map — 24 — 4
Potion — 14 — 7
Phoenix Feather — 7 — 4
Each object can either be taken once or not taken at all.
What is the maximum total magical power Hermione can carry without exceeding the weight limit?
